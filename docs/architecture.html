Единая БД: cinesync

Все сервисы используют одну MongoDB базу cinesync (после миграции из раздельных баз). Каждый сервис пишет только в свои коллекции.

Взаимодействие сервисов

Все межсервисные вызовы используют заголовок X-Internal-Secret. Клиенты напрямую обращаются только к публичным API через JWT.

Service-to-Service вызовы

notification ← все сервисы
Кто посылает уведомления
  • user → POST /notifications/internal/send
  • watch-party → POST /notifications/internal/send
  • admin → POST /notifications/internal/admin/broadcast
  • auth → POST /auth/internal/appeal-decision-email
user ← все сервисы
Получение FCM токенов и профилей
  • notification → GET /users/internal/:id/fcm-tokens
  • admin → POST /users/internal/admin/users/:id/block
  • watch-party → GET /users/internal/:id/restrictions
auth ← admin
Управление аккаунтами
  • admin → POST /auth/internal/create-staff
  • admin → DELETE /auth/internal/users/:id
  • admin → POST /auth/internal/:id/revoke-sessions
content ← watch-party
Домены и история просмотра
  • watch-party → POST /content/internal/domains/visit
  • watch-party → GET /content/blocked-domains
  • watch-party → POST /content/internal/history

Socket.io Events

WebSocket сервер на watch-party (:3004). JWT передаётся в handshake.auth.token.

Client → Server

Комната

  • room:join{roomId} — войти в комнату
  • room:leaveпокинуть текущую комнату
  • room:media:change{videoUrl, videoTitle?, videoPlatform?} — сменить видео (owner)
  • member:kick{targetUserId} — кикнуть участника (owner)
  • member:mute{targetUserId, reason?} — замутить (owner)

Видео

  • video:play{currentTime} — запустить (owner)
  • video:pause{currentTime} — пауза (owner)
  • video:seek{currentTime} — перемотка (owner)
  • video:heartbeat{currentTime} — позиция каждые 5с (owner)
  • video:buffer_startначало буферизации
  • video:buffer_endбуферизация закончена

Чат

  • room:message{message} — текст макс 500 символов
  • room:emoji{emoji} — эмодзи реакция
  • reaction:send{emoji} — анимированная реакция

WebRTC Mesh

  • mesh:joinвойти в P2P mesh сеть
  • mesh:peer_offer{toUserId, sdp} — SDP offer
  • mesh:peer_answer{toUserId, sdp} — SDP answer
