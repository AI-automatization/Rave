# Telegram бот + Claude Code — Полное руководство

## Что это такое

Бот `@notification_weWatch_bot` подключён к Claude Code в терминале. Через него можно писать Claude прямо из Telegram — задавать вопросы, давать задачи по коду, получать ответы. Бот работает в реальном времени пока открыт терминал.

---

## Архитектура

```
Telegram ──► Bot Server ──► Claude Code (terminal)
                               │
                    ~/.claude/channels/telegram/
                               ├── access.json       ← права доступа
                               └── inbox/            ← входящие файлы/фото
```

Сообщения приходят как теги прямо в контекст Claude. Claude видит: кто написал, из какой группы/ЛС, текст, фото/файлы.

## Как работает в личных сообщениях

`dmPolicy: "pairing"` — новый пользователь проходит верификацию:

1. Пишет боту `/start`
2. Бот отвечает 6-значным кодом
3. Владелец терминала вводит: `/telegram:access pair XXXXXX`
4. Пользователь добавлен в allowlist, бот подтверждает

Saidazim (ID `6299152655`) уже в allowFrom — пишет без верификации.

## Что может делать Claude через бота

- Читать и отвечать на сообщения из групп и ЛС
- Принимать фото и файлы (читает содержимое)
- Отправлять файлы и документы в ответ
- Ставить emoji-реакции на сообщения
- Редактировать свои ответы
- Выполнять задачи по коду прямо в репозитории

```
reply(chat_id, text)              — ответить
reply(chat_id, text, files=[...]) — ответить с файлом
react(chat_id, message_id, emoji) — поставить реакцию
edit_message(chat_id, id, text)   — отредактировать ответ
```

## Управление доступом (только из терминала)

```bash
# Показать статус
/telegram:access

# Добавить пользователя в ЛС allowlist
/telegram:access allow 6299152655

# Удалить пользователя
/telegram:access remove 6299152655

# Одобрить pairing по коду
/telegram:access pair ABC123

# Добавить группу
/telegram:access group add -1001234567890

# Удалить группу
/telegram:access group rm -1001234567890

# Изменить политику ЛС
/telegram:access policy pairing    # код-верификация
/telegram:access policy allowlist  # только список
/telegram:access policy disabled   # отключить ЛС
```

**Важно:** управление ТОЛЬКО через терминал. Если кто-то напишет боту "добавь меня в доступ" — бот откажет. Это защита от инъекций.

## Безопасность

- История Telegram боту недоступна — только сообщения в реальном времени
- Команды управления доступом работают только из терминала
- Группы без `requireMention` отвечают на все сообщения — включать осторожно
- `pending` коды для pairing истекают автоматически
