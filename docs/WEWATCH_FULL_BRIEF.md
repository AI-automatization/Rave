## ЧТО ТАКОЕ WEWATCH

### Одна строка
WeWatch — социальная платформа для совместного просмотра видео в реальном времени.

### Проблема
Друзья и близкие живут в разных городах и странах. Они хотят вместе смотреть фильмы, сериалы, видео — но не могут. Zoom не создан для этого. Обычные стриминги не поддерживают совместный просмотр. В Узбекистане и СНГ нет ни одного нормального решения.

### Решение
WeWatch синхронизирует видео у всех участников комнаты в реальном времени. Один человек создаёт комнату, вставляет ссылку на видео, приглашает друзей — и все смотрят одновременно с общим чатом, реакциями и голосовым общением. Один нажимает паузу — у всех пауза. Перематывает — все перематывают.

### Миссия
Сделать совместный просмотр таким же естественным, как сидеть рядом на диване — независимо от расстояния.

### Позиционирование
> "Диван на двоих. Экраны разные."

WeWatch — это не просто синхронизация видео. Это социальная платформа, где просмотр фильмов становится событием: с друзьями, с реакциями, с соревнованием, с достижениями.

## НИШA И РЫНОК

### Целевая аудитория

**Ядро:** Молодёжь 16–28 лет, Узбекистан + русскоязычное СНГ.

**Контекст почему это работает:**
- Узбекистан — молодая страна: 70% населения до 30 лет
- Высокое проникновение смартфонов, активная культура совместного досуга
- Студенты разъезжаются по разным городам, пары на расстоянии, друзья в разных странах
- Местного аналога нет вообще

**Боль конкретная:**
- "Давай посмотрим кино вместе" → звонят в Zoom → ставят видео на паузу → синхронизируют вручную → теряют момент → бросают
- WeWatch убирает эту боль полностью

### Конкуренты

#### Западные — не работают на нашем рынке

| Продукт | Почему не конкурент |
|---------|---------------------|
| **Teleparty** | Только Netflix/Disney+ — недоступны в Узбекистане |
| **Watch2Gether** | Только YouTube, нет мобильного приложения, нет соц. фич |
| **Kast** | Сложный, desktop-only, ориентирован на западную аудиторию |
| **Scener** | Chrome extension, только западные стриминги |
| **Amazon Watch Party** | Только Prime — нет в регионе |

#### Локальные конкуренты в Узбекистане

**Прямых конкурентов — НОЛЬ.**

В России были слабые попытки (Кинопоиск совместный просмотр — закрыт, VK Video party — ограниченный функционал), но они не работают в Узбекистане и не имеют мобильного приложения с геймификацией.

### Конкурентное окно

Сейчас — идеальный момент для выхода:
- Рынок созрел (смартфоны, быстрый интернет)
- Конкурентов нет
- Молодёжь ищет новые форматы досуга
- Время входа: сейчас или никогда — если не мы, через 1–2 года появятся другие

### Конкурентные преимущества WeWatch

1. **Первые в Узбекистане** — window of opportunity прямо сейчас
2. **Любой источник видео** — YouTube, VK, Rutube, прямые MP4 ссылки (не только один стриминг)
3. **Мобильное приложение** — нативное, не просто веб в браузере
4. **Геймификация** — Battle, Achievements, Leaderboard, ранги (конкуренты этого не делают)
5. **Полноценная социальная сеть** — профили, друзья, DM чат, история просмотров
6. **Локальный контент** — VK и Rutube = весь русскоязычный и СНГ контент

### Основные функции

#### Watch Party (главная фича)
- Создать комнату с любым видео (YouTube / VK / Rutube / прямая ссылка)
- Пригласить друзей по invite-коду или ссылке
- Синхронный просмотр: play/pause/seek синхронизируется у всех участников
- Лайв-чат во время просмотра
- Emoji реакции — летят по экрану как на TikTok
- Голосовое общение прямо в комнате
- Если кто-то буферит — все ждут автоматически

#### Социальные функции
- Профиль: аватар, имя, bio, статистика просмотров
- Система друзей: добавить / принять / удалить
- DM чат: личная переписка между пользователями
- Push уведомления: "твой друг создал комнату", "тебя пригласили"
- История просмотров + "Продолжить смотреть"

#### Геймификация (чего нет у конкурентов)
- **Battle** — вызов друга: чей фильм лучше? Голосуют оба
- **Achievements** — достижения за активность (первый просмотр, 10 часов, 50 друзей...)
- **Leaderboard** — публичный рейтинг самых активных зрителей
- **Ранги** — система уровней: Новичок → Киноман → Синефил → Легенда

### Поддерживаемые видео источники

| Источник | Примеры |
|----------|---------|
| YouTube | Любое публичное видео |
| VK Video | Весь русскоязычный контент |
| Rutube | Российские фильмы, сериалы |
| Прямые ссылки | .mp4, .m3u8 — любой онлайн-кинотеатр |

### Основной сценарий использования

```
1. Регистрация (email + подтверждение)
2. Настройка профиля → аватар, имя
3. Главный экран → активные комнаты / лента друзей
4. Создать комнату → вставить ссылку на видео (YouTube, VK...)
5. Поделиться invite-кодом с другом в Telegram/WhatsApp
6. Друг заходит → оба смотрят синхронно
7. Чат, реакции, голос → полноценный совместный просмотр
8. После → статистика, новые достижения, предложить следующий фильм
```
