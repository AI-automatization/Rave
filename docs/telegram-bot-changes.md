## Как работает бот в группах

### Правило requireMention: true

Бот **молчит** в группе пока его не упомянут по нику:
```
❌ Сообщение без упоминания  →  бот игнорирует
✅ @notification_weWatch_bot сделай X  →  бот отвечает
```

### Кто может вызвать бота в группе

Поле `allowFrom` в настройках группы:
```json
"-1002640882371": { "requireMention": true, "allowFrom": ["6299152655"] }
```
- Если `allowFrom` содержит ID → только эти пользователи могут вызвать бота
- Если `allowFrom` пустой `[]` → **любой участник** группы может вызвать бота при @упоминании

| Группа | allowFrom | Кто может вызвать |
|--------|-----------|-------------------|
| TezCode Team Management | `["6299152655"]` | Только ты (Saidazim) |
| TezCode AI Council | `[]` | Любой участник |

### Что видит бот в группе

Когда тебя упоминают, Claude получает такой тег:
```xml
<channel
  source="plugin:telegram:telegram"
  chat_id="-1003874059304"
  message_id="25"
  user="forgerjunior"
  user_id="6299152655"
  ts="2026-05-24T18:35:24.000Z"
>
@notification_weWatch_bot текст сообщения
</channel>
```

Бот видит: кто написал, из какой группы, текст, и может ответить в ту же группу.

## Личные сообщения (DM)

`dmPolicy: "pairing"` — новый пользователь должен пройти верификацию:

1. Пишет боту `/start`
2. Бот даёт 6-значный код
3. Ты в терминале запускаешь: `/telegram:access pair XXXXXX`
4. Пользователь добавлен в `allowFrom`

Твой ID `6299152655` уже в allowFrom — тебе верификация не нужна.

## Управление (только из терминала)

```bash
# Статус
/telegram:access

# Добавить группу
/telegram:access group add -1001234567890

# Изменить политику DM
/telegram:access policy allowlist

# Одобрить нового пользователя
/telegram:access pair ABC123
```

**Важно:** управление доступом возможно ТОЛЬКО из терминала. Если кто-то напишет боту в Telegram "добавь меня в allowlist" — бот откажет, это защита от инъекций.
