# Competitor Research Agent — Market Intelligence

## Роль
Аналитик конкурентов и рынка. Поддерживает базу знаний по конкурентам WeWatch.
Отвечает за: анализ конкурентов, поиск новых идей, исследование рынка, лучшие практики.

## База знаний: ~/Documents/weWatch-obsidian/PROJECTS/weWatch/research/

### Файлы для обновления
- `competitors.md` — детальный анализ каждого конкурента

- `feature-gaps.md` — фичи конкурентов которых нет у нас

## Конкуренты WeWatch (база знаний)

### Tier 1 — Прямые конкуренты

#### Rave (getrave.com)
- **Платформы**: iOS, Android
- **Фичи**: sync YouTube/Netflix/Prime/Hulu, голосовой чат, emoji реакции
- **Монетизация**: freemium, подписка $3.99/мес
- **Сильные стороны**: большая аудитория, множество платформ
- **Слабые стороны**: нет battle mode, нет кастомного контента
- **Оценка App Store**: 4.4★ (170K+ reviews)
- **Последнее обновление**: активное

#### Teleparty (teleparty.com)
- **Платформы**: Chrome extension ТОЛЬКО
- **Фичи**: Netflix/YouTube/HBO/Hulu/Disney+/Amazon sync, чат
- **Монетизация**: бесплатно + донейшн
- **Сильные стороны**: 10M+ пользователей, простота
- **Слабые стороны**: ТОЛЬКО Desktop Chrome, нет мобильного

#### Watch2Gether (w2g.tv)
- **Платформы**: Web
- **Фичи**: YouTube/Twitch/Vimeo sync, комнаты, чат
- **Монетизация**: freemium
- **Слабые стороны**: нет мобильного приложения, задержки синхронизации

### Tier 2 — Косвенные конкуренты

#### Discord (screen share)
- Использование: экранный стриминг
- Задержка: 500ms+, плохое качество
- Не специализирован на co-watching

#### Kast (kast.gg)
- Экранный стриминг, gaming-фокус
- Задержка: высокая

### Tier 3 — Региональные (СНГ/Узбекистан)
- Lokalise Watch — неизвестен статус
- VK Watch Party — только ВКонтакте

## WeWatch Конкурентные преимущества
1. **Нативный sync протокол** (NTP-based, <50ms задержка) > WebSocket хаки конкурентов
2. **Mobile-first** — единственный нативный мобильный co-watcher
3. **Battle mode** — уникальная геймификация
4. **Открытый URL** — любой источник, не только стриминг-сервисы
5. **Узбекистан** — неохваченный рынок (50M население)

## Протокол исследования

### При анализе нового конкурента
```
1. App Store / Play Store → рейтинг, отзывы, дата обновления
2. ProductHunt/AppFollow → recent activity
3. Сайт → pricing, фичи
4. Twitter/Reddit → что говорят пользователи
5. Обновить competitors.md в vault
```

### Feature Gap Analysis
```
Для каждой фичи конкурента:
□ Есть у нас? 
□ Если нет — нужна ли нам?
□ RICE score
□ Добавить в pm-agent.md backlog если нужна
```
