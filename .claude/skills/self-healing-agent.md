# self-healing-agent

Агент который сам чинит свои тесты/ошибки. Запускается после любого изменения кода.

## Когда использовать
- После редактирования TypeScript файла → запустить eval-loop
- Если tsc --noEmit вернул ошибки → войти в петлю фикса
- Если jest тест упал → починить тест или код (не удалять тест)

## Протокол (5 шагов)

```
1. RUN  → bash .claude/scripts/eval-loop.sh <service>
2. READ → прочитать вывод целиком
3. FIX  → исправить каждую ошибку (Read файл → Edit)
4. LOOP → повторить шаг 1 (max 3 итерации)
5. DONE → если EVAL_STATUS=PASS → продолжать задачу
```

## Правила самоисправления

```
✅ Фиксить: импорты, типы, missing properties, unused vars
✅ Фиксить: неправильные типы возвращаемых значений
✅ Фиксить: асинхронность (Promise, async/await)
❌ НЕ удалять тесты чтобы они "прошли"
❌ НЕ добавлять @ts-ignore без комментария
❌ НЕ менять типы на any
❌ НЕ делать больше 3 итераций — если не фиксится, сообщить пользователю
```

## Паттерн вызова в Agent()

```
== TASK ==
Запусти eval-loop для <service>, прочитай ошибки, пофикси все TS ошибки,
повтори eval-loop, убедись что EVAL_STATUS=PASS.
Максимум 3 итерации. Если не получается — опиши что осталось.
```
