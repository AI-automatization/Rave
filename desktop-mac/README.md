# WeWatch Desktop — macOS (reja bosqichida)

Mac uchun WeWatch klient: veb-ilova (`app.wewatch.uz`) + Virtual Browser (VB) egasining kompyuterida, VB oynasi tovushi bilan WebRTC orqali xonaga uzatiladi.

Holat: **boshlang'ich**. Hozircha kod yo'q — reja va ovoz sinovi (spike) bosqichida.

- Windows versiya (Polat): `desktop/` papkasi, `polat/dev` branchi (PR #265). Bu papka u bilan to'qnashmaslik uchun `desktop-mac/` deb nomlangan.
- Til: TypeScript (strict), Electron 45. Tarqatish: imzosiz DMG (hozircha).
- DRM (Widevine) 1-versiyada yo'q.
